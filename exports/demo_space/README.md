# VoiceEnv — live demo (shareable)

**One link for socials:** the same interactive demo from the AI Dev Summit talk.

1. Pick a real banking call (WAV)
2. Watch autonomous ingest → environment YAML
3. Per-turn comparison: real caller audio vs human agent vs AI agent
4. Grounded multimodal judge (Gemini vs expert call)
5. Env-driven prompt improvement (3.33 → 3.83 avg on this sample)

This Space runs a **pre-recorded replay** (no API keys). Clone the repo and run `voiceenv ui` for the full live pipeline.
